# Security Policy

Prompt Guard is a defensive scanning tool. If you find a security issue in
this project itself (e.g. an unsafe pattern in how it clones/reads
repositories, or a way to bypass detection that has security impact for
users relying on it), please report it privately rather than opening a
public issue.

## Reporting a Vulnerability

Open a GitHub issue marked `security` with as much detail as possible
(steps to reproduce, affected version/commit), or contact the maintainer
directly through the profile linked on this repository. Please avoid
including exploit details usable against third parties in a public issue.

You can expect an initial response within a few days. There is no bug
bounty program; this is a personal open-source project maintained on a
best-effort basis.
